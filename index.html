About This Project

Understanding disk scheduling algorithms is crucial for operating system performance optimization.

This visualizer helps students and professionals understand how different disk scheduling algorithms work by providing interactive simulations with real-time visualization of disk head movement and performance metrics.

The project demonstrates how different algorithms can significantly impact total seek time and overall disk I/O performance.

Disk scheduling is done by operating systems to schedule I/O requests arriving for the disk. The goal is to minimize the seek time and maximize the disk bandwidth utilization.

SSTF (Shortest Seek Time First) selects the request with the minimum seek time from the current head position. While FCFS is simple, SSTF can significantly reduce average response time by serving nearby requests first.
